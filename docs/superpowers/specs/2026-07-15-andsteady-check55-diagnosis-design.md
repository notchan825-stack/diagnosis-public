# くつ・あし・あるく黄金チェック55診断 — 設計書

2026-07-15作成・のっちゃん社長承認済み

## 背景・目的

andsteadyの新規獲得策を「LINE登録」主軸から「メルマガ登録＋8日間無料メール講座」主軸へ切り替える方針の一環。8日間講座の途中で「無料診断はこちら」というリンクを送り、既存のメルマガ登録者にさらに深く関わってもらうためのミニ診断アプリ。

登録済みメルマガ読者だけが講座メール経由でたどり着く前提のため、**このアプリ自体は新規のメール送信・メアド収集を一切行わない**（すでに社長本人が「これはノウハウだから、メアドない人にはやってあげられない」と明言している価値を、メルマガ登録者だけに提供する）。

## 全体の導線（このアプリのスコープ外部分も含む）

```
LP（メルマガ登録フォーム）
  → メルマガ登録（既存の外部配信システム abjan.biz）
  → 8日間無料メール講座（既存）
    → 講座内のどこかの回に「無料診断はこちら」リンク
      → 【本アプリ】くつ・あし・あるく黄金チェック55診断
        → 55問回答 → その場で結果表示（画面のみ・メール送信なし）
```

## 画面構成

1問1画面 or 5カテゴリーごとにまとめて表示、いずれかは実装時にdiagnosis-publicの既存パターン（sotsugyo等）に合わせる。

- **くつチェック**（14項目）
- **あし（FOOT）チェック**（11項目）
- **あし（LEG）チェック**（11項目）
- **あるくチェック**（15項目）
- **姿勢チェック**（4項目）

項目文言は `salon.andsteady.com/service/checksheet/` の黄金チェック55と完全一致させる（本人が既に告知・運用している項目名のため、勝手に変えない）。

## 判定ロジック（優先順位つき決定木）

チェックされた項目から、以下の順で判定する。**上から順に該当すれば即確定**（スコアの合計では判定しない）。

1. **外反母趾**（最優先）: 「外反母趾で靴がない」「外反母趾」のいずれかにチェックがあれば確定
2. **たこ・魚の目**: 「タコ・魚の目」にチェックがあれば確定
3. **体の外側トラブル群**: 「小指がいつも痛くなる」「すねの外が痛くなる」「内反小趾・寝指」「O脚」「XO脚」「X脚」「膝下が外側に変形している」「腰痛・膝痛・肩こり」のいずれかにチェックがあれば確定
4. **フォールバック（上記いずれにも該当しない場合）**: 5カテゴリー（くつ／FOOT／LEG／あるく／姿勢）のうち、チェック数が最多のカテゴリーの一般回答を表示。同数の場合は「くつ→FOOT→LEG→あるく→姿勢」の順で先に来る方を採用

将来的に「このパターンはやっぱり外反母趾と同格にしたい」等の追加要望があれば、この決定木に随時ルールを足していく（今回はここまでで確定・拡張は別タスク）。

## 回答文面

### 優先度1〜3（外反母趾／たこ・魚の目／体の外側トラブル群）

正本は `OneDrive/◆初回メール文例集.txt`（デスクトップの `◆初回メール文例集.lnk` から辿れる）の該当セクションをそのまま使う。

- 外反母趾 → 同ファイル「◆外反母趾」セクション
- たこ・魚の目 → 同ファイル「◆足裏タコ・魚の目・開張足」セクション
- 体の外側トラブル群 → 同ファイル「◆O脚・内反小趾・小指が痛い・寝指（体の外側トラブル）」セクションを基本文面とする。「腰痛・膝痛・肩こり」のみで他の外側トラブル項目にチェックがない場合は、代わりに「◆腰痛」セクションの文面を使う

### フォールバック5パターン（本人執筆・確定）

**①くつカテゴリー**
```
靴選びで悩まれているとのこと。
合う靴が見つからない場合には、
靴ではなく、足の問題であるケースも多いのです。

そして、合わない靴選びと歩き方が、足を崩してしまっている可能性も高いです。

足と靴は相性ですので、
おそらく、足に合う靴とともに、痛くならない足づくりを行うことをおすすめします。
```

**②FOOTカテゴリー**
```
足の形状にお悩みがあるとのこと。偏平足、浮き指、巻き爪など、
足のトラブルのほとんどが「浮き指」からスタートしています。

合わない靴を履くことで、足指は靴が脱げないように動き、浮き指になって、
本来の働きをしないことで、筋力不足となり、開張足となります。

筋肉は何歳からでもつけられますので、
まずは足指がしっかり使える靴環境を整えることが第一歩です。
```

**③LEGカテゴリー**
```
むくみやだるさ、脚の太さといったお悩みは、実は「歩き方」に原因があることが多いです。
正しく歩くことで、むくみや冷えが解消され、代謝があがっていくのです。

それは、靴が脱げないように無意識に歩いていると、
足指～足裏～ふくらはぎ～太もも～お尻が連動して動かず、
血を巡らせるポンプがうまく働かないからです。

まずは脂肪ではなく、余計な水分を脚から追い出す「歩き方」を身に着けることをおすすめします。
```

**④あるくカテゴリー**
```
歩くことにお悩みがあるとのこと。
歩くとすぐ疲れる、音が気になる、つまづきやすいといったことは、
足が本来の働きをしていないサインです。

歩き方を習ったことのある日本人は１割もいません。
そして、長年の歩き方のクセは１日ではなおりません。

ですからまず、自分の歩きかたを自覚するところからはじめましょう。
```

**⑤姿勢カテゴリー**
```
姿勢にお悩みがあるとのこと。

猫背や反り腰、重心の置き場所に迷うといったことは、
実は足もとの不安定さに原因があることが多いです。

ぐらつく足をカバーしようと、体の他の部分ががんばってしまう。
結果、姿勢の崩れに繋がっていく。

実は、背筋から遠い足もとを整えることが、姿勢改善の一番の近道なのです。
```

各回答の最後に、くつトレ®・ご予約への軽いブリッジ文を1文添える（文言は実装時に文例集の既存の結び方に揃える）。

## 技術構成

- 既存リポジトリ `diagnosis-public`（Next.js・Vercel自動デプロイ）に新ルートを追加（例: `/andsteady-check55`）。うごきどき診断・ひとり社長卒業診断（`/sotsugyo`）と同じ構成パターンを踏襲
- **バックエンド・DB不要**：55問の回答と判定ロジックはすべてクライアントサイド（React state）で完結。送信ボタンはなく、回答→即座に判定→結果表示
- メール送信機能・顧客データの保存は行わない（このアプリはメルマガ登録者向けの使い捨てエンゲージメントコンテンツという位置づけ）
